# Hospital Coordination · Team Kinetic

The product is implemented in [`ambulance-flow/`](ambulance-flow/README.md): a pickup-to-handover simulator with patient-carrying ambulance movement, dynamic Overview forecasts, case-dependent hospital queues, historical/live inputs and matched nearest-versus-coordinated policy evaluation. Travel currently uses explicitly labelled estimates, as authorized for the demo.

Existing private deployment (may predate local changes): [Open Kinetic](https://kinetic-ambulance-flow.chummydrake19.chatgpt.site).

See the [application README](ambulance-flow/README.md) for setup, architecture, API documentation, assumptions, and tests.
